zeropi.display

A Pi Zero e-ink display for live Claude Code usage

A gauge of current consumption against the rolling rate-limit windows, backed by a daily history graph — read from local Claude Code session logs, no paid API key required. Runs on reused pwnagotchi Pi Zero + Waveshare e-ink HAT hardware.
